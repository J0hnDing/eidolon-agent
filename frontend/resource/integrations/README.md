# Integration icons

GitHub, Notion, and Telegram marks are vendored from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons). Simple Icons is distributed under CC0; brand marks remain subject to their respective brand policies. Telegram uses its brand blue (`#26A5E4`). Files are stored locally so rendering does not contact a third-party host.

- Google: [official full-color G asset](https://www.google.com/images/branding/googleg/1x/googleg_standard_color_128dp.png).
- WhatsApp: symbol paths from the [official website's header logo](https://www.whatsapp.com/), without the wordmark, in WhatsApp green (`#25D366`). See [Meta's brand guidelines](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/).
- WeCom: [official Tencent SVG](https://www.tencent.com/wp-content/uploads/2022/12/wecom-1.svg), as used on the [WeCom product page](https://www.tencent.com/products/wecom/).

Microsoft uses its four-color window mark. The other integrations use generic interface symbols. Only the monochrome GitHub and Notion marks are inverted in dark mode; colored brand marks retain their original colors in both themes.
